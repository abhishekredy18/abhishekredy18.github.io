CMS & Product Chatbot for TaxBandits and Tax990

Dec 2025 – Present | SPAN Enterprises LLC, Fort Mill, SC Python • React • LangChain/LangGraph • MCP • RunPod • Professional Work

Project Overview

A central content management system built in Python and React that powers product content and chatbot knowledge for the live TaxBandits.com and Tax990.com applications. One system feeds both the public product pages and the AI assistant, so content edits and knowledge updates ship from a single place.

Access Control & MCP

Role-based access control governs users, permissions, and content workflows. CMS operations are also exposed as Model Context Protocol (MCP) tools, so AI agents can read and manage content through the same governed interface humans use.

Product Chatbot

A customer-facing chatbot and feedback loop built on LangChain and LangGraph, with agentic tool calling wired to the TaxBandits developer APIs — the assistant can look up real product capabilities instead of guessing.

Document Extraction

Models fine-tuned and deployed on RunPod extract structured data from user-uploaded tax form images, feeding validated fields straight into the product workflows.
