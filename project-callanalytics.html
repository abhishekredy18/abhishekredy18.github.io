Call Analytics Platform

Dec 2025 – Present | SPAN Enterprises LLC, Fort Mill, SC Whisper • Speaker Diarization • Qwen 8B • Docker • Professional Work

Project Overview

A production call analytics platform built for a 50-person customer support team handling 9,000+ calls per month. The system turns raw call recordings into searchable transcripts, concise summaries, and per-representative performance metrics, giving team leads a continuously updated view of call quality without listening to a single recording.

ML Pipeline

  • Transcription: Whisper converts every recording into accurate, timestamped transcripts.
  • Speaker Diarization: Separates representative and customer speech so metrics and summaries attribute statements to the right speaker.
  • LLM Analysis: A self-hosted Qwen 8B LLM scores sentiment, classifies call topics, and flags risky calls for review.

Grounded Chat Assistant

A chat assistant answers natural-language questions over the analyzed call corpus. Every answer cites the source calls behind it, keeping responses grounded in what was actually said rather than model speculation.

Deployment & Privacy

The entire platform is deployed with Docker on the company's internal network, so sensitive call data never leaves the building — transcription, LLM inference, and search all run in-house.
